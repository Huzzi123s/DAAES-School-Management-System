# DAAES School Management System

This repository is initialized for the project workflow.

## Branch strategy
- `main`: stable production-ready code
- `stage`: staging branch for review and testing before merge

## Contributor workflow
1. Create a feature branch from `stage`
2. Push your work
3. Open a pull request to `stage`
4. Review and merge into `stage`

This file was added to establish the repository baseline so the `stage` branch can be created cleanly.
